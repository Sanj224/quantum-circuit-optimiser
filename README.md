# README
## Project Overview

This submission contains the source code for a quantum circuit optimisation framework based on  ZX calculus. The system implements a multi-objective optimisation approach using simulated annealing, with support for hardware-aware optimisation and customisable cost functions.

## How to Run the Project

The primary interface for this project is provided through an interactive Jupyter notebook.

### Step 1: Set up a virtual environment
```python -m venv venv```
```venv\Scripts\activate```   # On Windows

### Step 2: Install required dependencies
```pip install -r requirements.txt```

### Step 3: Launch Jupyter Notebook
```jupyter notebook```

### Step 4: Open the documentation notebook

Open the file:

documentation.ipynb
This notebook contains the full tutorial on how to use this library
